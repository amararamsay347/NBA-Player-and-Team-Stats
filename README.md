# NBA Team Statistics

## Dataset and Source 
The dataset consists of a CSV file containing historical NBA basketball statistics, with recorded dates ranging from November 1946 to October 2026:
- TeamStatistics.csv: 146,768 rows and 59 columns, containing team game records with variables such as scores, shooting percentages, rebounds, turnovers, home or away status, and game outcomes.

Source: [NBA Dataset: Box Scores and Stats (1947 - Today)](https://www.kaggle.com/datasets/eoinamoore/historical-nba-data-and-player-box-scores)

## Purpose and Relevance

The purpose of this dataset is to analyze team performance and identify statistical patterns associated with winning basketball games. The file supports analysis at the team levels. This makes the dataset relevant to sports analytics, where statistical evidence can help evaluate players, compare teams, and understand changes in playing styles over time.

## Research Questions
1. How do shooting percentage, rebounds, and turnovers differ between winning and losing teams?
2. How does playing at home versus away relate to a team’s winning percentage?

## Selection Requirements
The dataset exceeds the minimum size requirements, with over 146,000 team records, containing 59 columns. It includes numerical variables such as points and rebounds, categorical variables such as team names, and sufficient information for EDA and questions about factors associated with winning. It comes from an identifiable publisher on Kaggle, has a reported CC0 public-domain license, and contains public sports statistics without sensitive personal information.
